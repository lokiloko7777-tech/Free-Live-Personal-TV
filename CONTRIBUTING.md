# Contributing

Hvala na doprinosu projektu Free Live Personal TV.

## Quick start
1. Fork + clone repozitorijum.
2. `npm install`
3. `npm run dev`
4. Otvori `http://localhost:8080`

## Branching
- `main` je stabilna grana.
- Kreiraj feature branch: `feat/<short-name>` ili `fix/<short-name>`.
- Jedan PR treba da rešava jednu temu.

## Commit poruke
Preporučeni format:
- `feat: ...`
- `fix: ...`
- `docs: ...`
- `refactor: ...`
- `test: ...`

## PR pravila
- Opisati problem i rešenje.
- Dodati test plan i rezultat smoke testa.
- Ažurirati dokumentaciju ako menjaš API/UI ponašanje.
- Izbegavati nepotrebne refaktore van scope-a.

## Coding smernice
- Zadrži postojeći stil koda.
- Ne uvoditi nove zavisnosti bez jasnog razloga.
- Ne hardkodovati tajne, API ključeve ili poverljive podatke.

## Report i diskusija
- Za bugove i feature zahteve koristi issue template.
- Za bezbednosne prijave koristi SECURITY.md.
