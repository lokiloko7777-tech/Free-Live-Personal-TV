# Security Policy

## Supported versions
Trenutno se bezbednosne ispravke rade na aktivnoj grani `main`.

## Kako prijaviti ranjivost
Nemoj otvarati javni issue za ranjivosti koje mogu biti zloupotrebljene.

Pošalji detalje kroz GitHub Security Advisory (preferred) ili privatni kanal maintainera.

U prijavi navedi:
- opis ranjivosti,
- korake za reprodukciju,
- potencijalni uticaj,
- predlog mitigacije (ako postoji).

## Očekivani SLA
- Prva potvrda prijave: do 72h.
- Procena ozbiljnosti i plan ispravke: što je pre moguće, zavisno od kompleksnosti.

## Scope
U scope ulaze backend API, auth/session tokovi, upload/decrypt pipeline, moderation/admin endpointi i deployment konfiguracija.
