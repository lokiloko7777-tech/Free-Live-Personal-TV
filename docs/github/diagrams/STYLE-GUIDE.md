# Diagram Style Guide

## Visual standard

Svi dijagrami koriste isti Mermaid `init` blok:

- theme: `base`
- primary/background palette:
  - background: `#101828`
  - primary blocks: `#1d2939`
  - borders/lines: `#93c5fd`
  - text: `#ffffff`

## Naming standard

- Numeracija: `00-...`, `01-...`, ...
- Nazivi kratki i domen-specifični
- Jedan glavni koncept po fajlu

## Structure standard

- Naslov fajla: `# NN Name`
- Jedan glavni Mermaid blok
- Kratak `Notes`/`Scope` deo gde je potrebno

## Reading strategy

Koristi preporučeni redosled iz [README.md](README.md) za onboarding od globalnog ka detaljnom pogledu.
